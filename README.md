## About Me

Hi, I’m **hidewood**, a Computer Science undergraduate at **BUPT**.

I enjoy turning ideas into small, usable products—from Windows desktop tools and backend services to grounded AI agents. My current focus is learning how to build agentic systems that are reliable, inspectable, and useful beyond a demo.

- Building with Python, FastAPI, Flask, Vue, and SQLite / MySQL
- Learning AI agent architecture, tool use, state management, and evaluation
- Studying machine learning, computer systems, and parallel computing
- Writing clear technical notes and documenting project decisions

I prefer software that is simple to understand, explicit about its boundaries, and dependable in real use.

## How I Work

- Start with a small, testable core and make the boundaries explicit.
- Keep model output constrained when deterministic code can make the decision.
- Treat failure states, privacy, and recovery as part of the product.
- Write down what worked, what did not, and why.
